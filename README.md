
# Ecommerce Cart with Login and Register

This project is an e-commerce cart application with user authentication features like login and registration. It is built using React, Vite, ESLint, Prettier, and Tailwind CSS.

## Features

- User Registration and Login
- Add to Cart functionality
- Responsive Design
- Built with modern tools like React and Tailwind CSS

## How to Use the Project

1. Fork the repository.
2. Clone it to your local machine.
3. Install dependencies using `npm install`.
4. Start the development server using `npm start`.

## Setup and Installation

1. **Clone the repository:**
   ```sh
   git clone https://github.com/khanramjan/Ecommerce-Cart-with-Login-Register.git
   ```
2. **Navigate to the project directory:**
   ```sh
   cd Ecommerce-Cart-with-Login-Register
   ```
3. **Install dependencies:**
   ```sh
   npm install
   ```
4. **Run the development server:**
   ```sh
   npm start
   ```
   The application will be available at `http://localhost:3000`.
